# Issue Tracker

**Tracker**: Local markdown.

Issues and specs live as Markdown files under `docs/specs/` in this repo. They
are not published to GitHub Issues, even though the repo has a GitHub remote
with Issues enabled.

Each spec is one file, named `<slug>.md`. Triage state is recorded in the
spec's own frontmatter rather than as tracker labels.

**Triage labels**: the five canonical roles, each label string equal to its
name.

- `needs-triage`
- `needs-info`
- `ready-for-agent`
- `ready-for-human`
- `wontfix`

**PRs as a request surface**: off.

## Domain docs

Single context. `CONTEXT.md` and `docs/adr/` at the repo root.
